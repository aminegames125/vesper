## Vesper

A fast, light IPTV player with a cloud of its own.

### Downloads

| What | File |
| --- | --- |
| Windows app (server included) | `Vesper_…_x64-setup.exe` / `.msi` |
| Linux app (server included) | `.AppImage` / `.deb` / `.rpm` |
| Android and Android TV | `Vesper-…-android.apk` |
| Server, Windows | `vesper-server-…-windows-x64.zip` |
| Server, Linux x64 | `vesper-server-…-linux-x64.tar.gz` |
| Server, Linux arm64 | `vesper-server-…-linux-arm64.tar.gz` |
| Server, Docker | `ghcr.io/aminegames125/vesper-server` |

Every file has a `.sha256` next to it. macOS and iOS are not built.

### Highlights

- Redesigned app: Home, Live TV, a timeline Guide, Favourites, dark and light themes, animated icons.
- Built-in recorder in Rust. No ffmpeg. Works on desktop, Android and Android TV.
- **Vesper Cloud**: lite and full server with an admin panel, cloud recording, scheduled recording, short retention, sync and a stream proxy.

See the [server guide](https://github.com/aminegames125/vesper/blob/main/docs/SERVER.md) to set up your cloud.
