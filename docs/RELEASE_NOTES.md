## Vesper

Record IPTV from Kodi: a Kodi add-on plus a self-hosted recording server for Linux, Windows and Docker.

### Downloads

| What | File |
| --- | --- |
| Kodi add-on | `plugin.video.vesper-….zip` (or install the [Vesper repository](https://amineos.dev/vesper/kodi/repository.vesper/repository.vesper-1.0.0.zip) to get updates automatically) |
| Server, Windows | `vesper-server-…-windows-x64.zip` |
| Server, Linux x64 | `vesper-server-…-linux-x64.tar.gz` |
| Server, Linux arm64 | `vesper-server-…-linux-arm64.tar.gz` |
| Server, Docker | `ghcr.io/aminegames125/vesper-server` (amd64 and arm64) |

Every file has a `.sha256` next to it. macOS builds of the server are not provided.

See the [Kodi guide](https://github.com/aminegames125/vesper/blob/main/docs/KODI.md) and the [server guide](https://github.com/aminegames125/vesper/blob/main/docs/SERVER.md) to set it up.
